# @openmrs/esm-starter-app

OpenMRS ESM Starter Application - A basic template for building OpenMRS ESM modules.

## Overview

This package serves as a starter template for developers looking to create OpenMRS ESM modules. It provides a simple structure and example code to help you get started quickly.

## Features

- **Basic Structure**: A well-organized project layout for ESM modules
- **Example Components**: Sample React components to demonstrate functionality
- **Configuration Guide**: Instructions on how to configure the module in OpenMRS

## Configuration

Configure the module in your OpenMRS configuration:

```json
{
  "@openmrs/esm-starter-app": {
    "exampleSetting": "exampleValue"
  }
}
```

## Development

```bash
yarn install    # Install dependencies
yarn start      # Start development server
yarn test       # Run tests
yarn lint       # Run linter
```
